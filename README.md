# Парсер вакансий Регионального кадрового центра Краснодарского края

Собирает вакансии медицинских организаций Краснодарского края с сайта
[медкадрыкубань.рф](https://xn--80aackbd0bcms3a1b4gta.xn--p1ai/vacancy)
и формирует два PDF-каталога: отдельно для выпускников медицинских вузов
и отдельно для выпускников медицинских колледжей (ссузов).

## Что делает

1. Открывает страницу `/vacancy`, забирает CSRF-токен и cookie сессии.
2. Постранично обращается к внутреннему JSON API сайта
   (`POST /api/vacancy/list`) и получает вакансии по 60 штук.
3. Сохраняет результат в `data/vacancies.csv` (UTF-8 с BOM — открывается в Excel).
4. Прогресс пишется в `data/progress.json`, чтобы при обрыве можно было
   продолжить с той же страницы, а не начинать заново.
5. Из собранного CSV генерирует два PDF:
   - `output/vacancies_vuz.pdf` — для врачей и специалистов
     с высшим сестринским образованием;
   - `output/vacancies_suz.pdf` — для среднего и младшего
     медицинского персонала (колледжи).

## Требования

- Python 3.10+
- VS Code (или любой другой редактор)
- Windows, Linux или macOS
- Системные библиотеки для WeasyPrint (см. раздел ниже)

## Системные зависимости

Помимо Python-пакетов, генератор PDF использует библиотеку **WeasyPrint**,
а ей нужны системные библиотеки рендеринга (Pango, cairo, GDK-Pixbuf,
GObject). Через `pip` они не ставятся — это C-библиотеки, а не Python-код.

### Windows

Нужен **GTK3 Runtime**. Скачайте установщик и запустите:

https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases

Возьмите файл вида `gtk3-runtime-3.24.xx-xxxx-xx-xx-ts-win64.exe`.

После установки библиотеки окажутся в
`C:\Program Files\GTK3-Runtime Win64\bin`. Если Python их всё равно
не находит, задайте переменную окружения:

```powershell
[Environment]::SetEnvironmentVariable(
    "WEASYPRINT_DLL_DIRECTORIES",
    "C:\Program Files\GTK3-Runtime Win64\bin",
    "User"
)
```

После этого перезапустите терминал.

**Проверка**: `python -c "import weasyprint; print(weasyprint.__version__)"`.
Если версия печатается без ошибок — всё в порядке.

### Linux (Ubuntu / Debian / Mint)

```bash
sudo apt update
sudo apt install -y \
    libpango-1.0-0 \
    libpangoft2-1.0-0 \
    libgdk-pixbuf-2.0-0 \
    libcairo2 \
    libffi-dev \
    shared-mime-info \
    fonts-liberation \
    fonts-dejavu
```

`fonts-liberation` и `fonts-dejavu` — шрифты с поддержкой кириллицы.
Без них русский текст в PDF отобразится квадратиками.

### Linux (Fedora / RHEL)

```bash
sudo dnf install -y \
    pango \
    pango-devel \
    gdk-pixbuf2 \
    cairo \
    cairo-devel \
    libffi-devel \
    shared-mime-info \
    dejavu-sans-fonts
```

### macOS

```bash
brew install pango libffi
```

### Если WeasyPrint не запускается

Ошибка `OSError: cannot load library 'libgobject-2.0-0'` означает,
что системные библиотеки не установлены. Проверьте шаги выше для
своей ОС.

Альтернатива — заменить WeasyPrint на **Playwright** (Chromium
скачивается через `pip` и системных библиотек не требует).
См. раздел «Альтернативы» в конце.

## Запуск

### Для методиста — одна кнопка

**Windows**: дважды кликните по `run.bat` в корне проекта.

**Linux / macOS**: откройте терминал в папке проекта и выполните:

```bash
./run.sh
```

Первый раз нужно сделать скрипт исполняемым:

```bash
chmod +x run.sh
```

Что произойдёт:

1. Соберутся свежие вакансии с сайта (или продолжится сбор с той
   страницы, где остановился в прошлый раз).
2. Сгенерируются оба PDF.
3. Папка `output` откроется в файловом менеджере.

Ярлык на `run.bat` (или `run.sh`) можно положить на рабочий стол —
запуск сведётся к одному клику.

Если нужно поменять тексты или заголовки в PDF — правьте
`config/pdf.yaml` (см. раздел «Как править PDF»). Терминал
открывать не нужно.

### Для разработчика — вручную

Иногда полезно запустить шаги по отдельности: например, собрать
только PDF, не заходя на сайт (когда сайт недоступен, а данные уже
есть), или наоборот — только обновить CSV.

Перед запуском активируйте окружение:

```powershell
# Windows
.\.venv\Scripts\Activate.ps1
```

```bash
# Linux / macOS
source .venv/bin/activate
```

**1. Собрать вакансии:**

```bash
python src/parser.py
```

Скрипт сам продолжит с той страницы, где остановился. Чтобы начать
заново — удалите `data/progress.json`. Скрипт устойчив к обрывам
соединения: до 5 ретраев на страницу с экспоненциальной паузой,
пересоздание сессии и CSRF при 4xx.

**2. Сгенерировать PDF:**

```bash
python src/make_pdfs.py
```

На выходе:

```
output/
├── vacancies_vuz.pdf
└── vacancies_suz.pdf
```

## Как устроен парсинг

Сайт не отдаёт вакансии в HTML: страница `/vacancy` подгружает их
через AJAX. Запрос:

- **Метод**: `POST`
- **URL**: `https://xn--80aackbd0bcms3a1b4gta.xn--p1ai/api/vacancy/list`
- **Тело**: `multipart/form-data` c фильтрами формы, номером страницы
  `page` и CSRF-токеном `_csrf`
- **Ответ**: JSON вида `{ success, items[], pages: { total, per_page } }`

Поэтому парсер работает как обычный клиент этой API, а не парсит HTML.

Фильтры (район, специальность, размер ставки, меры поддержки) можно
добавить в словаре `fetch_page_raw` — см. поля `PVacancySearch[...]`.

## Классификация для PDF

Правила, какие вакансии попадают в какой PDF, задаются в
`config/pdf.yaml` в блоке `include` у каждой секции:

- `specialities` — список специальностей (точное совпадение,
  регистр не важен).
- `title_patterns` — список регулярных выражений, ищутся
  в названии вакансии.

Например, для ВУЗ это `"Врач"` в специальностях плюс шаблоны
названий, покрывающие заведующих и медсестёр (у выпускников
вузов бывает высшее сестринское образование). Для СУЗ — средний
и младший медперсонал.

Часть вакансий (например, медсёстры) может попадать сразу в оба
документа — это нормально, они идут для разных аудиторий.

Административный персонал и «Прочие» (водители, электрики,
программисты) не попадают никуда, потому что их нет ни в одном
списке специальностей.

### make_pdfs.py

- Если нужно добавить третью категорию документов (например,
  для работодателей) — просто добавьте новую секцию в
  `config/pdf.yaml`. Скрипт её подхватит автоматически.

## Как править PDF (для методиста)

Весь текст, заголовки и цвета PDF задаются в одном файле:
`config/pdf.yaml`. Программирование не нужно.

### Порядок работы

1. Откройте `config/pdf.yaml` в любом текстовом редакторе
   (Блокнот, VS Code).
2. Найдите нужную секцию: `vuz` — документ для вузов,
   `suz` — для колледжей.
3. Поменяйте тексты в кавычках. Кавычки удалять нельзя.
4. Сохраните файл.
5. Запустите сборку:
   - **Windows**: дважды кликните по `run.bat`.
   - **Linux / macOS**: `./run.sh` в терминале.
   - Если нужно пересобрать только PDF без похода на сайт —
     `python src/make_pdfs.py` вручную.
6. Откройте `output/vacancies_vuz.pdf` или
   `output/vacancies_suz.pdf` и проверьте.

### Что можно менять

- `title` — заголовок документа.
- `subtitle` — подзаголовок под ним.
- `description` — текст описания на титуле.
- `source` — подпись в подвале каждой страницы.
- `columns` — состав и порядок колонок в таблице.
- `support_flags` — какие меры поддержки выводить.
- `colors` — цвета (primary — тёмный, accent — светлый).
- `output` — имя итогового файла.
- `include` — какие специальности и шаблоны названий попадают
  в этот документ.

### Чего делать не надо

- Удалять кавычки вокруг значений.
- Менять отступы (важны в YAML).
- Писать пробелы между `key` и `:` (нужно `key:` без пробела).
- Использовать символ табуляции для отступов — только пробелы.

### Если что-то сломалось

Откройте `config/pdf.yaml` и убедитесь, что:

- все значения — в кавычках, кроме чисел;
- отступы сделаны пробелами, одинаковыми по уровню;
- нет лишних символов вроде `{`, `[`, `]` вне квадратных скобок списка.

Если не помогло — попросите администратора откатить файл из git
(прошлые версии всегда сохранены).

## Как править вёрстку (для дизайнера)

Основной шаблон — `templates/report.html`, оформление —
`templates/style.css.jinja`. Один и тот же шаблон используется
для обоих PDF; различия между документами (заголовок, описание,
колонки) задаются в `config/pdf.yaml`.

Если нужны разные шаблоны для ВУЗ и СУЗ:

1. Скопируйте `templates/report.html` → `templates/vuz.html`.
2. Отредактируйте копию как хотите.
3. В `config/pdf.yaml` у секции `vuz` замените
   `template: "report.html"` на `template: "vuz.html"`.

Кода это не касается.

Шаблоны используют Jinja2: `{{ переменная }}` подставляет значения
из `config/pdf.yaml`, `{% for ... %}` — циклы. Доступны переменные:

- `title`, `subtitle`, `description` — тексты из config.
- `total` — всего вакансий.
- `date` — дата формирования.
- `columns` — список колонок.
- `groups` — сгруппированные по районам вакансии.
- `config` — весь config для доступа к цветам и source.

Посмотреть, как выглядит HTML без данных, можно открыв
`templates/report.html` в браузере — таблица будет пустая, но
структура и стили видны.

## Альтернативы WeasyPrint

Если на компьютере нельзя поставить системные библиотеки (GTK,
Pango), WeasyPrint не запустится. В этом случае замените его на
**Playwright** — он скачивает собственный Chromium в папку
пользователя и не требует прав администратора.

Установка:

```bash
pip install playwright
playwright install chromium
```

Измените `src/make_pdfs.py`: замените импорт и функцию `render_pdf`
на версию с Playwright (пример в истории коммитов). Шаблоны
и `config/pdf.yaml` остаются без изменений.

## Лицензия и этика

Проект — для внутреннего использования Региональным кадровым
центром. Парсинг выполняется с задержками и не создаёт нагрузку
на сайт. Правила сайта (`robots.txt`) разрешают обход:
`Disallow:` пуст.
