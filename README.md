# Парсер вакансий Регионального кадрового центра Краснодарского края

Собирает вакансии медицинских организаций Краснодарского края с сайта
[медкадрыкубань.рф](https://xn--80aackbd0bcms3a1b4gta.xn--p1ai/vacancy)
и формирует два PDF-каталога: отдельно для выпускников медицинских вузов
и отдельно для выпускников медицинских колледжей (ссузов).

## Что делает

1. Открывает страницу `/vacancy`, забирает CSRF-токен и cookie сессии.
2. Постранично обращается к внутреннему JSON API сайта
   (`POST /api/vacancy/list`) и получает вакансии по 60 штук.
3. Сохраняет результат в `data/vacancies.csv` (UTF-8 с BOM — открывается в Excel).
4. Прогресс пишется в `data/progress.json`, чтобы при обрыве можно было
   продолжить с той же страницы, а не начинать заново.
5. Из собранного CSV генерирует два PDF:
   - `output/vacancies_vuz.pdf` — вакансии для врачей (высшее образование);
   - `output/vacancies_suz.pdf` — вакансии для среднего и младшего
     медицинского персонала (колледжи).

## Запуск

### 1. Собрать вакансии

```bash
python src/parser.py
```

Скрипт сам продолжит с той страницы, где остановился в прошлый раз.
Чтобы начать заново — удалите `data/progress.json`.

Скрипт устойчив к обрывам соединения: до 5 ретраев на страницу с
экспоненциальной паузой, пересоздание сессии и CSRF при 4xx.

### 2. Сгенерировать PDF

```bash
python src/make_pdfs.py
```

## Как устроен парсинг

Сайт не отдаёт вакансии в HTML: страница `/vacancy` подгружает их через
AJAX. Запрос:

- **Метод**: `POST`
- **URL**: `https://xn--80aackbd0bcms3a1b4gta.xn--p1ai/api/vacancy/list`
- **Тело**: `multipart/form-data` c фильтрами формы, номером страницы `page`
  и CSRF-токеном `_csrf`
- **Ответ**: JSON вида `{ success, items[], pages: { total, per_page } }`

Поэтому парсер работает как обычный клиент этой API, а не парсит HTML.

Фильтры (район, специальность, размер ставки, меры поддержки) можно
добавить в словаре `fetch_page_raw` — см. поля `PVacancySearch[...]`.

## Классификация для PDF

- **ВУЗ** — вакансии с `speciality = "Врач"`.
- **СУЗ** — `speciality` в `{"Средний медицинский персонал",
  "Младший медицинский персонал"}`.
- Административный персонал и «Прочие» (водители, электрики, программисты)
  в PDF не попадают.
- Если категория пустая — определяется по ключевым словам в названии
  (`врач`, `медсестра`, `фельдшер`, `санитарка` и т.д.).

## Формат CSV

| Колонка           | Описание                                  |
|-------------------|-------------------------------------------|
| `url`             | ссылка на вакансию                        |
| `title`           | название должности                        |
| `speciality`      | категория (Врач / Средний / Младший)      |
| `organization`    | медицинская организация                   |
| `area`            | муниципалитет                             |
| `work_mode`       | режим работы                              |
| `vacancy_part`    | ставка                                    |
| `qty`             | количество мест                           |
| `updated`         | Unix-timestamp последнего обновления      |
| `mentors`         | флаг: наставничество (0/1)                |
| `housing`         | флаг: служебное жильё                     |
| `social_land`     | флаг: земельный участок                   |
| `social_communal` | флаг: компенсация ЖКХ                     |
| `zemskii`         | флаг: программа «Земский доктор/фельдшер» |
| `social_rent`     | флаг: компенсация аренды жилья            |
| `social_mortgage` | флаг: компенсация ипотеки                 |
| `social_deposit`  | флаг: социальный вклад                    |

## Настройки

### parser.py

| Переменная            | Где                  | Назначение                        |
|-----------------------|----------------------|-----------------------------------|
| `BASE`, `LIST_PAGE`   | начало файла         | адреса сайта                      |
| `DATA_DIR`, `CSV_PATH`, `PROGRESS_PATH` | начало файла | пути сохранения     |
| `FIELDS`              | список колонок CSV   | состав выходного файла            |
| задержка между страницами | `scrape_all`, строка `pause = 2.0 + random.uniform(0, 1.5)` | вежливость |

### make_pdfs.py

- `FONT`, `FONT_BOLD` — шрифт для PDF. Скрипт сам ищет TTF с кириллицей
  (DejaVu → Arial → Times → Liberation). Чтобы использовать свой —
  передайте путь в `register_fonts()`.
- `FLAGS` — какие меры поддержки выводить в колонку «Социальная поддержка».
- `classify()` — правила отнесения вакансии к ВУЗ/СУЗ.
